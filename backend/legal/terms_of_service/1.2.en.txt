10. HOW GAMES ARE ORDERED AND RECOMMENDED (RECOMMENDER SYSTEM)

10.1 The "Discover" screen shows lists of public games. The user chooses the list: "For you", "Trending", "Popular" or "New". The
list chosen decides the order in which games are shown.
10.2 Main parameters, in the order in which they are applied:
(a) Number of plays (parameter "total_plays"): how many times players started the game. Counted once per player per cooldown
window, so repeated re-entries do not inflate it. It is the first criterion in "For you" and "Trending" and the second in "Popular".
(b) Number of likes (parameter "likes"): the second criterion in "For you" and "Trending" and the first in "Popular".
(c) Publication date (parameter "created_at"): the only criterion in "New" (newest first).
(d) Age category of the game and of the account (parameter "age_category"): this is a safety filter, not a ranking criterion. An
account without a verified 18+ age assurance is shown only games marked as suitable for all ages.
(e) Recent play categories (parameter "recent_play_categories"): used ONLY in "For you" and ONLY if the user turns on
personalization (see 10.4). It is off by default.
10.3 By default the order is the same for every user with the same age access: it is based on how popular a game is, not on a
profile of the user. We do not use data from other websites or apps, we do not infer personal characteristics, and we do not
use payments or messages to rank games. [THE "RELATIVE IMPORTANCE" IS THE ORDER IN 10.2: THERE ARE NO NUMERIC WEIGHTS]
10.4 Personalization (optional, off by default). If the user turns on "Personalized recommendations" in Settings, then in "For
you" the games in the categories of the user's last played games (up to the 3 most frequent categories among the last 50 games
in "Recently played") are shown before the other games; inside each group, the order stays the one described in 10.2(a)-(b).
The user can turn this off at any time in Settings, and can clear "Recently played" history, which removes the signal. Turning
personalization off, or choosing another list ("Trending", "Popular" or "New"), returns to the order that does not use the user's
play history.
10.5 If we change these parameters, we update this section and bring the change to the user's attention as described in section 13.

not a trader, we show this and that EU consumer protection law does not apply to the contract with that seller. [LEGAL WORDING
AND THE CONTRACTUAL ROLE OF ASTRAN IN SHOP PURCHASES — TO BE CONFIRMED BY THE COMPANY]
